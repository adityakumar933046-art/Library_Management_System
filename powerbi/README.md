# 📊 Power BI Dashboard: Library Management System

This guide provides step-by-step instructions for creating the **Library Management System Dashboard** in Microsoft Power BI Desktop using the cleaned dataset.

---

## 📁 1. Data Import

1. Open **Microsoft Power BI Desktop**.
2. Click **Get Data** > **Text/CSV**.
3. Import the four cleaned CSV files located in `dataset/processed/`:
   - `books_cleaned.csv`
   - `members_cleaned.csv`
   - `borrowing_cleaned.csv`
   - `fines_cleaned.csv`
4. In the preview window, click **Load**.

---

## 🔗 2. Data Modeling & Relationships

Navigate to the **Model View** (left sidebar icon) and configure the following 1-to-Many (`1:*`) relationships:

| From Table (1) | Primary Key | To Table (*) | Foreign Key | Cardinality | Cross Filter |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `books_cleaned` | `book_id` | `borrowing_cleaned` | `book_id` | One to Many (`1:*`) | Single |
| `members_cleaned` | `member_id` | `borrowing_cleaned` | `member_id` | One to Many (`1:*`) | Single |
| `borrowing_cleaned` | `borrow_id` | `fines_cleaned` | `borrow_id` | One to Many (`1:*`) | Single |
| `members_cleaned` | `member_id` | `fines_cleaned` | `member_id` | One to Many (`1:*`) | Both / Single |

---

## 🧮 3. Key Performance Indicators (KPI Cards)

Create a dedicated Measures table or add these DAX measures to your model:

### Measure 1: Total Books
```dax
Total Books = COUNTROWS(books_cleaned)
```
*Visual: **Card** | Label: Total Books (50 titles)*

### Measure 2: Total Members
```dax
Total Members = COUNTROWS(members_cleaned)
```
*Visual: **Card** | Label: Total Members (50 patrons)*

### Measure 3: Total Borrowings
```dax
Total Borrowings = COUNTROWS(borrowing_cleaned)
```
*Visual: **Card** | Label: Total Loans (320 transactions)*

### Measure 4: Overdue Books
```dax
Overdue Books = 
CALCULATE(
    COUNTROWS(borrowing_cleaned),
    borrowing_cleaned[return_date] > borrowing_cleaned[due_date]
)
```
*Visual: **Card** | Label: Overdue Loans (106 records)*

### Measure 5: Total Fine Amount
```dax
Total Fine Amount = SUM(fines_cleaned[fine_amount])
```
*Visual: **Card** | Label: Total Fines ($1,695.00)*

## 📈 4. Visualizations & Charts

### Chart 1: Most Borrowed Books
- **Type**: Clustered Horizontal Bar Chart
- **Y-Axis**: `books_cleaned[title]`
- **X-Axis**: `[Total Borrowings]`
- **Filter**: Top N -> Top 5 by `[Total Borrowings]`
- **Title**: Top 5 Most Borrowed Books

### Chart 2: Popular Book Categories
- **Type**: Clustered Column Chart
- **X-Axis**: `books_cleaned[category]`
- **Y-Axis**: `[Total Borrowings]`
- **Sort**: Descending by `[Total Borrowings]`
- **Title**: Borrowing Distribution by Category

### Chart 3: Monthly Borrowing Trends
- **Type**: Line Chart
- **X-Axis**: `borrowing_cleaned[borrow_date]` (grouped by Year & Month)
- **Y-Axis**: `[Total Borrowings]`
- **Markers**: Enabled
- **Title**: Monthly Borrowing Activity (2023 - 2025)

### Chart 4: Department-wise Borrowing
*(Note: As the dataset schema uses `membership_type`, this chart reflects borrowing by member segment/tier).*
- **Type**: Donut Chart or Column Chart
- **Legend / Axis**: `members_cleaned[membership_type]`
- **Values**: `[Total Borrowings]`
- **Title**: Borrowing by Membership Type

---

## 🎛️ 5. Slicers / Interactive Filters

Place slicers at the top or side of the canvas:
1. **Year Slicer**: `borrowing_cleaned[borrow_date]` (Dropdown or Tiles: 2023, 2024, 2025).
2. **Category Slicer**: `books_cleaned[category]` (Dropdown).
3. **Membership Type Slicer**: `members_cleaned[membership_type]` (Buttons: Student, Faculty, General, Premium).

## 🎓 6. College Viva Quick Tips

When presenting this dashboard to examiners:
1. **Star Schema Model**: Explain how `borrowing_cleaned` acts as the central fact table connecting the dimension tables (`books_cleaned`, `members_cleaned`).
2. **Circulation Rate**: Point out that Fiction and Computer Science represent over 35% of all circulation.
3. **Overdue Risk**: Explain that 33.1% of loans incurred fines, indicating a need for automated return reminders.
4. **Data Refresh**: Explain that Power BI connects seamlessly to the cleaned CSV files generated by `python/data_cleaning.py`.
